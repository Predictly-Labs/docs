# Products

Predictly offers three types of prediction markets, each designed for different risk appetites and use cases.

## Market Types

### Full Degen Markets

Traditional prediction markets with full risk and reward. Winners take the losing pool.

[Learn More →](Prediction-Markets/Full-Degen.md)

### Zero Loss Markets

Protected markets using DeFi yield farming. Principal is always returned, only yield is distributed.

[Learn More →](Prediction-Markets/Zero-Loss.md)

### Private Markets

Group-exclusive prediction markets for friend competitions.

[Learn More →](Prediction-Markets/Private.md)

## Social Features

### Groups & Communities

Create private prediction communities with invite codes, custom roles, and leaderboards.

[Learn More →](Groups.md)

### Judge System

Fair market resolution through trusted friends acting as judges.

[Learn More →](Judge-System.md)

## Quick Comparison

| Feature  | Full Degen      | Zero Loss   | Private    |
| -------- | --------------- | ----------- | ---------- |
| Risk     | High            | None        | Varies     |
| Reward   | Full pool       | Yield only  | Full pool  |
| Access   | Public          | Public      | Group only |
| Best For | High conviction | Risk-averse | Friends    |
