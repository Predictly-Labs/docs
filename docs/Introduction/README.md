# Introduction

Predictly is a lightweight social prediction market platform designed for small groups of friends.

## What Makes Predictly Different?

Unlike traditional prediction markets that focus on large global events and feel complex, Predictly puts **playfulness, accountability, and social interaction** at the center of the experience.

## Core Concept

Create predictions within your friend group about anything relevant to your daily lives:

- Personal goals
- Monthly challenges
- Friendly competitions
- Fun, spontaneous bets

## Built on Movement Network

All transactions run on Movement Network, ensuring:

- Low fees
- Fast confirmation
- Smooth user experience
