# Mission

## Our Vision

Predictly aims to transform prediction markets from complex financial instruments into **fun, social experiences** for everyday friend groups.

## What We're Building

A consumer-friendly app that is:

- **Fun** - Playful and engaging
- **Simple** - No crypto knowledge required
- **Habit-forming** - Daily engagement through social features

While quietly leveraging the strengths of Web3 without making users feel like they're interacting with blockchain at all.

## Core Values

1. **Social-First** - Friends compete, not strangers
2. **Accessible** - Web2-like experience with Web3 benefits
3. **Transparent** - All outcomes verifiable on-chain
4. **Fair** - Trusted judges from within the community
